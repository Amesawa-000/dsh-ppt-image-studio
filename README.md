# PPT 配图工坊

为 DeepSeek Harness（DSH）接入生图 API。你可以在设置页面输入提示词生成图片，也可以让 agent 根据 PPT 的主题、页面内容和视觉风格编写提示词，再调用工具生成配图。

## 功能

- **图形化页面**：设置 → PPT 配图，包含 API 地址、密码式密钥输入、协议选择、模型下拉框和提示词编辑区。
- **一键检测**：尝试 OpenAI Images 兼容协议和 Gemini 原生协议，读取模型列表；检测不会触发生图。
- **模型选择**：从服务商返回的列表选择，也支持手动填写模型 ID。不内置可能过期的模型名单。
- **手动生图**：使用已保存的配置生成图片、预览、下载预览图并复制原始图片路径。
- **Agent 生图**：提供 `ppt_image_settings` 和 `ppt_generate_image`，返回可用于 PPTX 的原始图片路径及图片附件。
- **密钥与配置分开保存**：密钥保存在 DSH 凭据存储，地址、协议、模型和尺寸保存在插件配置。导出本插件目录不会包含密钥。
- **中英文界面**：跟随 DSH 语言和明暗主题，键盘可访问。

## 安装

适配 DSH `0.2.2-rc.3` 的插件接口，支持桌面版和提供 Web 设置页的本机部署。其他版本应先检查接口兼容性。

1. 获取发行包 `dsh-ppt-image-studio-1.0.0.tgz`，无需先解压。
2. 在 DSH 的 **插件 → 添加插件** 中填写这个本地包的绝对路径，确认安装并启用；也可以让 agent 调用 `plugin_manager`，以该路径为 `target` 执行 `install_bundle`。
3. 打开 **设置 → PPT 配图**。如果新页面尚未出现，刷新 DSH 页面；若安装结果明确要求重启，按提示重启。

这是 DSH 插件包，不放入 skills 目录。安装器会自动安装清单中的依赖。

开发者也可安装源码目录，但本地目录安装采用链接，不会替源码目录安装依赖。请先在目录中运行 `pnpm install --ignore-scripts --node-linker=hoisted`，再让插件管理器安装该目录；之后不要移动或删除源码目录。更新已加载的 JavaScript 后须按 DSH 的提示重启，不能仅凭入口还在就认为新代码已生效。


## 配置 API

1. 填写服务商提供的 **API 地址** 与 **API Key**。地址可以是 API 根地址，也可以是完整的 `images/generations` 端点。
2. 点击 **一键检测协议与模型**。程序只会在你填写的服务商 origin 内读取模型列表。
3. 在下拉框里选择支持生图的模型。服务商列表可能包含纯文本模型，请按服务商说明选择。
4. 选择尺寸或比例，点击 **保存配置**。
5. 在下方提示词窗口输入描述，点击 **生成图片**。

检测是尽力识别，并不代表服务商的全部能力都兼容。若模型列表不存在、检测有歧义或未列出生图模型，可手动选择协议并填写模型 ID 后保存。

| 协议 | 模型列表 | 生图接口 | 授权方式 |
| --- | --- | --- | --- |
| OpenAI Images 兼容 | `GET /models` | `POST /images/generations` | `Authorization: Bearer ...` |
| Gemini 原生 | `GET /models` | `POST /models/{model}:generateContent` | `x-goog-api-key` 请求头 |

接口路径会追加到 API 根地址。OpenAI 根地址未带版本时补 `/v1`；Gemini 根地址未带版本时补 `/v1beta`。自定义代理前缀与显式版本路径会保留。

更换 API 地址后，需要为新地址输入密钥。密钥按规范化地址分别存储，旧地址的密钥不会自动发送给新地址。清空输入框表示沿用当前地址已存密钥；删除密钥请使用专门的删除按钮。切换到新地址不会自动删除旧地址的记录。

## 在 PPT 任务中使用

在 DSH 聊天里提出 PPT 任务，例如：

> 制作一份关于可再生能源的 10 页 PPT。封面和章节页使用风格统一的配图。请调用 PPT 生图工具，自行编写提示词，保留标题留白，把图片放入对应幻灯片。

Agent 可先调用 `ppt_image_settings` 的 `status` 查看是否已配置，再调用 `ppt_generate_image`。工具提示会引导 agent 根据主题、色彩、构图和文字留白撰写提示词；它仍需使用 PPT 制作工具将图片插入幻灯片。

本插件负责生成和提供图片，**不独立生成 PPTX**。表格、数据图表和需要精确编辑的内容应由 PPT 工具制作；不要让生图模型编造数据或科研证据。

### 工具参数

`ppt_image_settings`：

- `action`：`status`、`detect`、`models` 或 `save`。
- `model`：可选，保存模型选择。
- `size`：可选，保存尺寸选择。
- 不接受 API Key；请在设置页面输入，避免密钥进入聊天记录。

`ppt_generate_image`：

- `prompt`：必填，1–16000 字符。
- `model`：可选，覆盖本次调用使用的模型。
- `size`：可选，覆盖本次调用使用的尺寸。
- 返回 `images` 数组，包含 `path`（原始图片的本地路径）、`attachment`、`name` 和预览入口。

同一个插件实例一次只处理一个生图请求，避免重复点击导致并发生图。

## 提示词示例

> 可再生能源主题演示文稿的章节配图：清晨的海上风电场，写实摄影风格，蓝绿配色，柔和自然光，主体位于画面右侧，左侧约三分之一保持简洁留白，不添加文字、标志或水印。画面用于 16:9 幻灯片。

可以明确主题对象、风格、主色、光照、构图和留白。中文标题建议在 PPT 中作为可编辑文本添加。

## 费用、隐私与限制

- 生图会调用你配置的第三方服务，可能计费。取消或超时不保证服务商停止处理或退款；插件不自动重试生图请求。
- 提示词会发送给服务商。不要在提示词中加入不应向该服务商披露的资料。
- Agent 调用的提示词与结果会进入 DSH 会话记录；手工输入密钥不会进入该工具的参数。凭据存储的具体保护方式取决于 DSH 部署，不将其描述为必然加密。
- 支持 HTTPS；只有 localhost 和回环地址允许 HTTP。API 地址不接受用户名、密码、查询参数或 fragment。
- 图片下载可使用 HTTPS 签名链接，不携带 API Key、不跟随重定向。跨 origin 的本地和内网 IP 字面量下载会被拒绝；这不是完整的 DNS rebinding 防护。
- 单次最多接收 4 张图片；单响应及图片合计限 32 MiB。实际图片还须通过 DSH 的图片格式与大小校验。
- 模型发现只读取一页，最多 500 个模型，单个 ID 最长 200 字符。不自动跟随分页；可手填列表外的模型。
- 默认生图超时为 120 秒。服务商只支持异步任务、特殊签名、Azure 特殊地址参数、Responses API、生图聊天协议或其他私有协议时，需要另写适配器。
- OpenAI 的尺寸是否支持由具体模型决定；Gemini 原生使用画面比例。错误时请按服务商文档调整。
- 预览是 DSH 规范化后的图片，原始图片另存为文件附件。最近预览最多保留 24 条内存索引，刷新设置页或重启后不提供历史图库；已返回的原始路径可继续使用，保存期限由 DSH 管理。
- 当前只提供文生图，不支持上传参考图、局部重绘或多轮改图。

## 开发与测试

源码为原生 JavaScript，无构建步骤。安装器按清单安装 Cordis 与 Schemastery 依赖；本包没有安装脚本。

源码目录包含协议与业务测试。使用 Node.js 24：

```sh
node --test --test-isolation=none adapters.test.js studio.test.js host.test.js
```

测试使用模拟 API，不需要真实密钥，不产生费用。真实服务商能否生图，仍需用户配置自己的 API 后验证。
